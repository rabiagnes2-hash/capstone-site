
# Agnes Rabi - Personal Portfolio

## About My Website

Welcome to my personal portfolio website. My website introduces me, displays my web development projects and provides a way for visitors to contact me.

## Website Pages

- **Home:** Introduction and welcome message.
- **About:** Information about me, my learning journey, skills and goals.
- **Projects:** Displays my web development projects.
- **Contact:** Contact information and a message form.

- Responsive design for mobile devices.
- Contact form with validation.
